# 自定义形象

## 用户已确认

允许用户选择一张形象图，基于同一角色生成喝水、走动和眼睛休息三段动画，预览后替换当前提醒形象。使用已登录的 Grok Bot 和现有 Webhook 例行任务，无需模型 API Key。

## 首次连接

1. 打开「提醒设置 → 自定义形象 → 配置 Grok」，点击「复制配置说明」。
2. 在负责生成视频的 Grok Bot 聊天里，将说明交给 Bot，编辑已有 Webhook 例行任务。确认它保留触发器，并添加了 `golden-paw-character-v1` 分支。
3. 在 Grok 的例行任务详情复制 Webhook 地址和密钥，填入「配置 Grok」。App 将连接保存到 Mac 钥匙串。
4. 让 Grok Bot 保持登录并连接此 Mac。生成期间如果 Grok 显示本地文件操作审批，按该设备当前设置处理。

## 生成与启用

选一张主体完整的 PNG 或 JPG，先看绿幕参考图的构图，再点击「生成三段动画」。也可以只生成当前所选动作。已有成片时，可以预览、单段重做或导入从 Grok 聊天保存的方形绿幕 MP4 / 透明 MOV。

三段都可预览后，「启用新形象」会将整套动画切换为当前形象。生成、抠像和预览期间继续使用已启用的形象。切回咕咕嘎嘎后仍可启用已保存的自定义形象。预览只在设置窗口播放，提醒依旧按各自间隔运行。

成片处理保留视频尺寸、帧时间戳和时长，通过 AVFoundation 导出无声 HEVC Alpha MOV 与末帧 PNG。建议使用主体完整、与绿色背景易区分的参考图；绿色服饰可能影响绿幕抠像效果。macOS 14 及更新版本会尝试为不带透明通道的单主体图抠出前景。请检查参考图和深浅两种背景下的透明预览。

## 本地任务协议

- 请求只包含协议名、任务 UUID、所选动作以及固定的 8 秒、方形参数。Grok 通过已连接 Mac 的本地文件传输能力读取参考图，用户无需发布图链。
- 任务目录固定在 `~/Library/Application Support/Golden Paw/CustomCharacter/Requests/<uuid>/`。App 先写入 `reference.png`，再向例行任务提交。
- Grok 完整写入 `<kind>.mp4` 后写 `<kind>.json`，成功收据含实际字节数。App 等待收据和文件大小一致，再生成透明版本。失败结果单独显示，上一版可用成片保留。
- 退出后重开可继续等待同一个任务。超时和传输状态不明时不会自动重发。已启用素材、草稿及状态保存在 `CustomCharacter/`。

## 验证

`make verify` 使用隔离存档模拟本地收件，覆盖截断文件拒绝、失败动作手动导入、整套启用、持久化、实际播放与切回默认形象。要用实际绿幕原片代替内置样片，可设置 `GUGU_CHARACTER_QA_SOURCE` 为本地 MP4 的完整路径。
