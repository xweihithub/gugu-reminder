# 定时提醒架构

更新：2026-11-06。

## 用户已确认

当前只保留喝水、走动、眼睛休息三类到期动画。移除召唤、常驻、立即提醒、跟随、小窝、任务对话及本机控制台入口。

## 当前实现

Electron 主进程 `src/desktop/main.cjs` 管理透明窗口、四项菜单、点击穿透、提醒计时器和存档。应用启动时窗口隐藏，到期或打开设置时显示。Windows 系统托盘、macOS 菜单栏和应用菜单使用同一份菜单定义，无召唤快捷键及手动预览接口。

`src/core/reminders.cjs` 负责三类间隔、暂停、恢复及下次时间；主进程每秒检查最早到期项，并通过 preload 发送到渲染进程。播放尚未确认完成时重复的同类事件不重启动画，多项同时到期时依次处理。

`src/desktop/preload.cjs` 仅暴露载入间隔、报告点击区域、完成提醒、保存间隔及接收事件五个能力。

`src/renderer/app.js` 管理提醒的入场、播放、眼睛休息倒计时、淡出以及设置面板。面板打开时到期提醒暂缓；保存间隔可取消对应旧排队提醒。没有常驻角色与工作任务状态。

`src/renderer/reminder-cinema.mjs` 播放本地 VP9 alpha 视频，减少动态效果及播放失败时显示同角色静帧。播放器经 esbuild 构建，视频本身不重新生成。

## 存档与边界

继续使用原应用 userData/state.json，保留已保存的提醒间隔及未来到期时间；旧存档的常驻和助理字段保留但不参与运行，也不返回给界面。通过临时文件加 rename 保存。唤醒时重新计算提醒，避免补播积压。

应用无需模型、网络接口或本机控制台；已移除 LangGraph 和 Three.js 运行依赖。历史原型不纳入本仓库，应用只打包 `src`、package.json 与必要运行依赖。播放器构建文件由启动和打包命令生成，不纳入版本控制。

## 待决定事项

多显示器、自启动及更多提醒类型尚未纳入当前版本。

## Windows 桌面版

Windows 与 macOS 共用透明 Electron 窗口、计时和动画。Windows 以可见的本地 PNG 企鹅图标提供托盘入口，左键打开设置，右键显示四项菜单；macOS 的跨工作区设置仅在 macOS 调用。显示器增减或缩放变化时重新布局。

`package:win` 使用 electron-builder 生成 x64 NSIS 当前用户安装程序，可选择目录，并创建桌面及开始菜单快捷方式；`package:win:dir` 输出可直接运行的完整目录。安装图标使用本地 ICO。内部应用名及存档标识继续保留 Golden Paw。
