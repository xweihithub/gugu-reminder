# 定时提醒原生架构

更新：2026-11-06。

## 用户已确认

保留喝水、走动、眼睛休息三类定时动画、间隔设置、稍后、暂停/恢复与退出。改为 macOS 原生实现，功能不变，视频质量和质感优先。召唤、常驻、跟随、任务对话及应用控制不恢复。

## 当前实现

Swift Package 无外部依赖，最低 macOS 13。`native/App/AppController.swift` 用 AppKit 管理菜单栏、设置、提醒窗口及 AVFoundation 播放器。三块独立非激活透明面板分别显示角色、回应区和设置；空白桌面保持点击穿透，在主显示器展示。

`native/Core/ReminderClock.swift` 管理三种独立计时、1–1440 分钟间隔、暂停及稍后。默认眼睛 40、走动 50、喝水 60 分钟。调度器每秒检查最早到期项，一次展示一条。设置打开时暂缓到期展示；修改项从保存时间或暂停结束后重排，其余项保留原时间。

`native/Core/ReminderSession.swift` 使用单调时钟管理入场、休息、回应和退场。正常入场 2.65 秒；喝水和走动在入场后等待 6.5 秒；眼睛休息 20 秒再保留 2.2 秒结束反馈。回应只提交一次。主动稍后为眼睛 5 分钟、其余 10 分钟，其余结束方式均使用正常间隔。

`native/App/Views.swift` 绘制设置与回应界面，角色由 AVPlayerLayer 按原比例适配播放，不裁切画面。视频无声播放一次，结束保留末帧；减少动态效果或播放器失败时使用对应 PNG。高频界面计时仅在提醒期间运行。

暂停一小时后从正常间隔计时；手动恢复及系统唤醒重排全部提醒，唤醒不补播睡眠积压。没有自动启动、后台服务、网络接口、模型密钥或额外系统控制权限。

## 存档与迁移

Bundle ID 继续使用 `com.zoey.goldenpaw`，存档继续位于 `~/Library/Application Support/Golden Paw/state.json`。沿用原 `reminders.intervals`、`next`、`pausedUntil` 结构和毫秒时间戳，保留仍有效的未来时间；无关历史根字段保留但不接入功能。使用同目录原子替换写入及 0600 文件权限。

Swift 原生代码替代 Electron 运行时，旧实现仅留在开发者本地 `artifacts/legacy-electron/` 和 Git 历史。应用包只包含原生可执行文件、Info.plist、三段 MOV 和三张 PNG。VP9 源素材、测试、制作中间文件与构建缓存均不打包。

## 验证和边界

`make test` 验证核心规则；`make verify` 在独立存档运行真实应用检查，包含实际定时到期、完整视频透明解码、AVPlayerLayer 展示、设置保存、暂停/唤醒、眼睛休息和降级流程。验证入口仅用于开发，不提供产品手动提醒入口。

Apple Silicon 已实机验证。Intel、更多显示器、自启动和更多提醒类型尚未验证或纳入当前版本；开发构建为 ad-hoc 签名，未公证。
